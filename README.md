# Supplementary Material

Supplementary Material for "Smart Maintenance of Human–Vehicle–Infrastructure Systems under Occluded Vehicle–Vulnerable Road User Conflicts: A Diagnosis–Prognosis–Decision Framework" by Jian-Peng Chang, Jia-Qi Liu, Zhen-Song Chen, and Wen-Long Shang.

Supplementary_Material.pdf contains Sections S1–S7: the full model definitions, the mode-response rules, the simulation setting, and the detailed results referred to in the main article.
